      Pengaturan & Panduan Webhook Google Apps Script (gviz / doPost) Panduan Teknis Guru

      Karena lingkungan pratinjau aplikasi web membatasi permintaan jaringan lintas-domain demi keamanan, data nilai disimpan secara aman melalui state aplikasi dan dapat langsung diekspor sebagai berkas .CSV atau disalin (TSV) untuk ditempel ke Google Sheets. Jika aplikasi ini di-hosting di server sekolah/domain sendiri, pasang skrip Google Apps Script berikut agar pengiriman data real-time berjalan otomatis tanpa kendala CORS:

      1. Buka Google Spreadsheet ID 1UUspNuNI60CxaU9skmIztTJKjqU-NYYDFXZ0UF-7Afo, pastikan baris 1 berisi header: Nama Siswa | Tanggal/Waktu | Topik Materi | Jumlah Soal | Benar | Nilai | Total Waktu | Rata-rata/Soal | Rekap Jawaban.
      2. Untuk akses baca publik (gviz / CSV stream), klik Bagikan (Share) → Ubah akses umum menjadi Siapa saja yang memiliki link (Pelihat).
      3. Untuk simpan otomatis, buka menu Ekstensi → Apps Script, tempel kode di bawah, lalu pilih Terapkan (Deploy) → Deployment baru → Aplikasi Web dengan akses Siapa saja (Anyone).
      const SHEET_ID = '1UUspNuNI60CxaU9skmIztTJKjqU-NYYDFXZ0UF-7Afo';

function doGet(e) {
  const sheet = SpreadsheetApp.openById(SHEET_ID).getSheets()[0];
  const rows = sheet.getDataRange().getValues();
  return ContentService
    .createTextOutput(JSON.stringify({ status: 'ok', rows: rows }))
    .setMimeType(ContentService.MimeType.JSON);
}

function doPost(e) {
  const sheet = SpreadsheetApp.openById(SHEET_ID).getSheets()[0];
  const data = JSON.parse(e.postData.contents);
  sheet.appendRow([
    data.namaSiswa,
    data.tanggalWaktu,
    data.topikMateri,
    data.jumlahSoal,
    data.benar,
    data.nilai,
    data.totalWaktu,
    data.rataRataDetik,
    data.rekapJawaban
  ]);
  return ContentService
    .createTextOutput(JSON.stringify({ status: 'saved' }))
    .setMimeType(ContentService.MimeType.JSON);
}
